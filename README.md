# Fldigi-nicFW880
Use Nicsure nicFW880 whith ham software FLDIGI
Xml file for Rig configuration in Fldigi

warning

- use usb isolator
- use an external antenna 

Test on nicFW880 v5.18.02 and Fldigi 4.2.11

Fichier RigCat : Rt-880-Nicfw.xml

that's work in this version :
- Frequency read,set
- Mode read,set
- S-Meter
- Bandwidth read,set
- PTT

Fichier Macro : Rt880Nfw.mdf
- select Vfo
- select mode Vfo
- Multiwatch
- Scan Presets
- Radio on
- Radio off
